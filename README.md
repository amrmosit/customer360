# Customer360 Django Application

This project is a practice implementation of a Django-based customer communication management system called **Customer360**. It was built to consolidate customer communication records in a central location, providing visibility into recent interactions.

## Project Description

Customer360 allows customer service teams to:
- Capture customer communication records (Channel, Direction, Summary)
- View interactions in the last 30 days
- Manage communications through a user-friendly interface

## Technologies Used

- **Python 3.11**
- **Django Web Framework**
- HTML/CSS (for templates)
- SQLite (default Django DB)

## Features

- Record new communication entries
- View a list of recent customer interactions
- Simple, professional interface for customer management
